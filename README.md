# Harsh's portfolio (Next.js)
1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in SMTP details (Gmail needs an App Password).
3. `npm run dev` then open http://localhost:3000
4. Edit everything in `app/data.js`: links, resume URL, photo (`photo: "/me.jpg"` after adding the file to `/public`).
5. Deploy on Vercel and add the same env vars in project settings.
